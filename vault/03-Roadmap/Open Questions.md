# Open Questions

Decisions that still need an answer. Move answers into the relevant design note and mark it `#agreed`.

- [ ] **Death penalty:** Deepwoken-style permadeath with lives, a soft penalty (lose some RC or rank progress), or none?
- [ ] **PvP rules:** always-on open world PvP, PvP only in certain wards, or opt-in?
- [ ] **Race selection:** chosen at character creation, or random roll (ghoul / human) like some Roblox RPGs?
- [ ] **Kagune type:** player chooses, or rolled with rarity?
- [ ] **Feeding on players:** can ghouls eat downed player humans? It's lore-accurate but needs moderation thought for a public Roblox game.
- [ ] **Gore level:** Roblox content rules limit blood and gore. Decide on a stylized approach early (for example red RC particles, not realistic blood).
- [ ] **IP:** Tokyo Ghoul is owned by Sui Ishida / Shueisha. Fan games on Roblox exist but can be taken down. Decide whether to use original character names only and avoid official art.
- [ ] **Monetization:** none, cosmetics only, or game passes? Avoid pay-to-win in a PvP game.
