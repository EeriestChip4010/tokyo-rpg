# Open Questions

Decisions that still need an answer. Move answers into the relevant design note and mark it `#agreed`.

- [x] **Death penalty:** permadeath. Exact rules still open, see [[Death and Permadeath]]. #agreed
- [x] **PvP rules:** always-on open world PvP. #agreed
- [x] **Race selection:** origin rolled at creation (Human, Born ghoul, rare Natural one-eyed); humans can join the CCG or take the transplant route in-game. See [[Origins and Race Paths]]. #agreed
- [x] **Kagune type:** rolled randomly. See [[Origins and Race Paths#Kagune roll]]. #agreed
- [ ] **Permadeath details:** lives count, what carries over after a wipe. See [[Death and Permadeath]].
- [x] **Feeding on players:** yes. Ghouls can eat a whole body or tear off limbs to grab and go. See [[Feeding]]. #agreed
- [x] **Gore level:** minimal blood particles. #agreed (check the experience's Roblox maturity rating before launch)
- [x] **IP:** players make their own characters; keep the series' original names for mechanics and lore terms (kagune, RC cells, CCG, kakuja, and so on). #agreed Risk noted: fan games can still be taken down.
- [x] **Monetization:** cosmetics plus a few game passes. #agreed Keep passes non-pay-to-win (for example extra outfit slots, emotes), since the game has permadeath and open PvP.
