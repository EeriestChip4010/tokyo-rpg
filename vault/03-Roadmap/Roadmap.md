# Roadmap

Target: a **first playable** with combat (M1, dash, block, dodge), one basic kagune, one basic quinque, and basic lore-grounded progression, built for public multiplayer.

## Steps
- [x] **1. Design vault**: this Obsidian vault with lore and design notes.
- [ ] **2. Roblox project setup**: Rojo project, folder layout, shared combat framework, server-authoritative remotes (see [[Multiplayer and Networking]]).
- [ ] **3. Combat prototype**: M1 chain, dash, block, parry, dodge, posture; one kagune (Rinkaku) and one quinque (C-rate issue blade); tested against an NPC dummy (see [[Combat System]], [[Kagune Design]], [[Quinque Design]]).
- [ ] **4. Basic progression**: RC level, hunger, kagune maturity, investigator rank, quinque familiarity, data saving (see [[Progression]]).

## After the first playable
- Map: a first Tokyo ward (the 20th ward, with an Anteiku-style café hub)
- Remaining kagune types and quinques
- Kakuja path and threat-rating raids
- Quinx path
- Factions (Anteiku, Aogiri Tree)
