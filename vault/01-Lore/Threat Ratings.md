# Threat Ratings

How the CCG ranks ghouls by danger. #canon

| Rating | Meaning (roughly) |
|---|---|
| C | Weak; can be handled by low-rank investigators |
| B | Moderate |
| A | Dangerous; needs experienced investigators |
| S | Very dangerous; Special Class involvement |
| SS | Extremely dangerous |
| SSS | Catastrophic (for example the One-Eyed Owl) |

- Ratings can carry a `+` or `−` (for example S+, A−) and change as the CCG learns more. #canon
- Notable ghouls get a codename (for example "Centipede", "Rabbit", "Gourmet"), often from their mask or behavior. #canon
