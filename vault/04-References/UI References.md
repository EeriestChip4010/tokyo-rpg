# UI References

The hub for design references from other games: HUDs, stat screens, menus, level-up flow. For what the Tokyo Ghoul series itself says, use the lore notes in `01-Lore`.

## Games
- [[Deepwoken - HUD and Screens]]: bars, posture, cooldown icons, telegraphs, attribute investment, talent cards, character creation, the death and wipe flow
- [[Ghoul Re - HUD and Screens]]: minimal HUD, the 4-column skill tree, ghoul and CCG rank ladders, rolled clans
- [[Tokyo RE - HUD and Screens]]: stamina-driven combat with Skill Burst, ghoul parkour against CCG gadgets, PvE-to-PvP rank progression (few public screenshots, so it needs in-game checks)
