# Kagune Design

Each kagune type plays differently, following the lore strengths and weaknesses in [[Kagune Types]].

## How kagune work in-game
- Releasing the kagune changes your M1s to kagune M1s and unlocks kagune skills.
- Kagune M1s and skills cost **RC**. Running low on RC weakens the kagune. Running out forces it to retract. (Lore: [[RC Cells]], [[Ghoul Diet]].)
- The kagune can be **damaged**: enough hits on it cause a brief "severed" state where skills are unusable while it regrows. Rinkaku regrow fastest, Koukaku resist severing.
- The [[Kakugan]] shows while the kagune is out, and this matters for the stealth and identity systems (see [[Progression]]).

## Type identities (first-playable scope: one type to start)
| Type | Playstyle | Signature idea |
|---|---|---|
| Ukaku | Fast, ranged pressure | Crystal shard volley. Burns RC quickly, so it needs to be used in bursts. |
| Koukaku | Tank, heavy hitter | Shield stance that blocks without losing posture, but slows movement. |
| Rinkaku | Aggressive brawler | Grab-and-slam tentacles. Heals on hit, but its kagune is easy to sever. |
| Bikaku | Balanced, technical | Long sweeping tail with a guard-breaking spin. |

Recommendation: build **Rinkaku** first. It's the series' most iconic type (Kaneki, Rize), and its kit exercises grabs, healing and severing, which tests most of the combat framework.

## Matchups
Apply a modest damage bonus (around 10–15%) following the lore cycle in [[Kagune Types#Matchups]]. Keep it small so skill still decides fights.
